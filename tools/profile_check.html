Profile Preflight

Drop a profile .csv here before you send it. Everything runs in this page — the file is never uploaded anywhere. The checks below are the defects that get past the server's own upload validation and only show up later, on a tablet.

Choose a profile CSV or drag the file onto this panel

How to save the file so the server accepts it. In Excel, Save as → CSV UTF-8 (Comma delimited). The plain CSV (Comma delimited) option cannot store characters like ₂ or ≥ and silently replaces them with ?.

Checks run entirely in your browser. Nothing is sent over the network.
